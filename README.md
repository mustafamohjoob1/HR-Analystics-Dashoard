# HR Analytics Dashboard

## Project Overview
This Power BI dashboard analyzes HR data and helps track workforce performance, employee trends, and HR KPIs.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Key KPIs
- Total Employees
- Active Employees
- Turnover Rate
- Average Salary
- Department Headcount

## Dashboard Insights
- Tracks employee distribution by department
- Shows employee status and turnover trends
- Helps management understand workforce performance
- Supports HR reporting and decision-making
